PROJECT TITLE: Batalha Acadêmica

PURPOSE OF PROJECT:
RPG de turnos em pixel art feito em Java com o Greenfoot (projeto de
faculdade). Um estudante universitário enfrenta quatro matérias:
Cálculo, Álgebra Linear, Programação em Java e Estrutura de Dados.

VERSION or DATE: 1.0

HOW TO START THIS PROJECT:
Abra o cenário no Greenfoot, clique em Compile, depois em Run.
Clique uma vez dentro do jogo para ele receber o teclado.

AUTHORS: (seu nome aqui)

USER INSTRUCTIONS:
Escolha uma matéria e vença-a antes que ela vença você.

  [1] Resolver Questão   dano = conhecimento           (-5 de energia)
  [2] Estudar            +10 energia, +3 conhecimento
  [3] Usar Conhecimento  dano = conhecimento x 2       (-20 de energia)
  [4] Descansar          +20 vida, +5 energia

Seus ataques podem ser CRÍTICOS (+50% de força, 15% de chance).
A matéria ganha energia a cada turno e usa ataques cada vez mais fortes.
Dica: estude antes de enfrentar as matérias mais difíceis!

CONTROLES
  1 a 4 ................ escolher ação
  SETAS ou MOUSE ....... navegar
  ENTER, ESPAÇO, CLIQUE  confirmar
  ESC .................. voltar
  M .................... liga/desliga o som

ASSETS
A arte atual é provisória (pixel art desenhada em código). Para usar
PNGs, coloque-os em images/ e registre o caminho em ImageLibrary
(lista AVAILABLE). Sons (.wav) vão em sounds/ e são registrados em
SoundManager. O jogo funciona normalmente sem nenhum som.
